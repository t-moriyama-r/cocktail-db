# アフィリエイト表示 API(`GET /api/affiliates`)の決定

#47 で作る、商品の欄に出すアフィリエイトを返す API の、旧と変えるところ。

## 旧との差分

- 商品の行が無いノード・銘柄、または無い ID で呼んだとき: 旧は `アフィリエイトデータ未作成` の例外で 500 を返し、旧の画面はエラーを握りつぶして欄を出さなかった。新は 404 を返す。画面(#303)は旧と同じく欄を出さない(決めた人: t-moriyama-r、PR #431 のコメントで「A(404)でよい」)
- ノードの行が無く、同じカテゴリの下に銘柄の行があるとき: 旧は、ノードの行をカテゴリの ID だけで探していたため、その銘柄の行を 200 で返した。新は行が無い扱いで 404 を返す(旧の収集はすべてのカテゴリの行を作るので、本番でこの形の行はまず無い)
