# 説明文を区切りの並びにして返す(公開 API)

#286 で決めたこと。説明文(`description`)とカクテルの補足(`note`)に入った参照の記法(`@n<ID>@`・`@c<ID>@`・`@b<ID>@`・`@d<ID>@`。#285)を、画面がそのまま描ける区切りの並びにして返す。変換は `App\Support\DescriptionParser` が受け持つ。旧の `Markup::generateDiscriptionArray` を移したもの。保存のときの変換(#287)は `docs/decisions/description-markup.md`、画面での描き方は #301。

## 決まったこと

1. **区切りは 2 種類**。文字の区切り `{type: "text", text}` と、リンクの区切り `{type: "node"|"cocktail"|"brand"|"dictionary", id, text, has_youtube}`。並びは説明文に書いた順
2. **リンクの区切りの `text` はリンク先の名前**(旧と同じ)。2 段より深いノードも名前だけ(旧のミドルと同じ。親の名前は付けない)
3. **`has_youtube` はリンク先の `youtube` が null・空でないとき true**。旧は動画のあるリンク先を橙色で出していた(#301)
4. **文字は HTML にしない**。改行は改行のまま返す(旧は `nl2br` で `<br />` を足していた)。`<` などもそのまま返し、文字として描くのは画面(#301)
5. **記法の種類は `n`・`c`・`b`・`d`**。大文字(`@N12@` など)も同じ意味で読む(保存のとき大文字は書いたまま残すため。`description-markup.md` の決まったこと 1)。ID は 1 から始まる数字。この形でない `@`(メールアドレス・旧の `@p`・`@m`・閉じていない記法など)は文字のまま
6. **指す先の無い参照は、記法を取り除く**(消したページへのリンクが残っていたもの。編集で開くときの `withNotes` と同じ扱い)。int に収まらない桁の ID も同じ
7. **下書きのカクテルを指す参照は、名前だけの文字にする**。公開の詳細が 404 になる(`cocktail-detail.md` の決まったこと 1)ので、リンクにしない。管理者が下書きを見る管理 API(`GET /api/admin/cocktails/{id}/preview`)でも同じ並びを返す
8. **続いた文字の区切りは 1 つにつなげ、空の文字の区切りは入れない**(6・7 で文字になった前後もつなげる)
9. **説明文が null・空の文字なら null**(旧と同じ)
10. **返す API**: いまはカクテルの詳細(`GET /api/cocktails/{id}`)と管理者の詳細(`GET /api/admin/cocktails/{id}/preview`)の `description`・`note`(#40)。新着動画(#39)・カテゴリ(#42)・銘柄(#43)・用語(#46)の API は、まだ無いので、それぞれの issue で `DescriptionParser` を通して返す

## 旧との差分

テストの表では `差分あり(意図: docs/decisions/description-parts.md)` としてここを指す。旧の結果は、旧ソース(本番の `laravel13` の `Markup::generateDiscriptionArray`・`Detail/component/description.vue`)を読んで置いたもので、旧システムでは確かめていない(旧の実行環境が無いため)。

- 区切りの形: 旧はリンクを `{command: "C"|"P"|"M"|"B"|"D", id, txt, is_youtube}`、文字を `{txt}` で返していた → 新は `{type: "cocktail"|"node"|"brand"|"dictionary", id, text, has_youtube}` と `{type: "text", text}`(#286 の「やること」1。カテゴリとミドルは `node` にまとめる)
- 改行: 旧は文字の区切りを `nl2br` にかけ、改行の前に `<br />` を足していた → 新は改行のまま返す(#286 の「受け入れ条件」。決まったこと 4)
- 指す先の無い参照: 旧は見つからないリンク先で型のエラーになり、説明文を返す API ごと HTTP 500 になっていた → 新は記法を取り除く(#286 の「やること」2。決まったこと 6)
- 下書きのカクテルを指す参照: 旧は下書きにもリンクしていた → 新は名前だけの文字(#286 の「やること」2。決まったこと 7)
- 用語へのリンクの動画: 旧は用語のリンクに `is_youtube` を付けず、動画があっても橙色にならなかった → 新は用語も、動画があれば `has_youtube` が true(#286 の「やること」1 がすべての種類に `has_youtube` を返すとしている)
- 空の文字の区切り: 旧は説明文を `@` で分けていたので、参照で始まる・終わる・参照が続く説明文では、空の `{txt: ""}` が入っていた → 新は空の文字の区切りを入れず、続いた文字はつなげる(決まったこと 8)
- 記法でない `@`: 旧は説明文を `@` で分けていたので、記法でない `@`(メールアドレスなど)が消えていた → 新は文字のまま残す(決まったこと 5)
- 文字の中の英字と数字: 旧は `@` で分けた文字の中に、記法の英字(`c`・`p`・`m`・`b`・`d` とその大文字)と数字が続く所(`B52を` など)があると例外になり HTTP 500 になっていた → 新は文字のまま(決まったこと 5)
- 旧の記法 `@p`・`@m`: 旧はカテゴリ・ミドルへのリンクにしていた → 新は記法の種類に無いので文字のまま(#285 の「やること」1 で、移行のときに `@n` に直す)
