# 説明文を、リンクの区切りの並びにして返す(公開 API)

#286 で決めたこと。記法そのもの(`@n<ノードの ID>@`・`@c`・`@b`・`@d`)は #285 で決める。変換は `App\Support\DescriptionParser` が受け持ち、説明文(`description`)とカクテルの補足(`note`)を返す公開 API は、これを通して返す。いま通しているのは、カクテルの詳細(`GET /api/cocktails/{id}`)と、管理者のプレビュー(`GET /api/admin/cocktails/{id}/preview`)と、新着動画(`GET /api/cocktails/latest-video`。#39)。カテゴリ(#42)・銘柄(#43)・用語(#46)の API は、作るときに通す。

## 決まったこと

1. **説明文を、文字の区切りとリンクの区切りの並びにする**。説明文の順に並べる
   - 文字の区切り: `{"type": "text", "text": "…"}`
   - リンクの区切り: `{"type": "node"|"cocktail"|"brand"|"dictionary", "id": <ID>, "text": "<指す先の名前>", "has_youtube": <指す先に動画があるか>}`。`has_youtube` は、指す先の `youtube` が null・空の文字でないとき true
2. **記法は `@<種類><ID>@`**。種類は `n`(ノード)・`c`(カクテル)・`b`(銘柄)・`d`(用語)で、大文字も同じ意味(#287 で大文字のまま保存するため)。ID は 1 から始まる 18 桁までの数字(経路の ID と同じ)。この形でない `@`(メールアドレス・ほかの英字の記法・桁の多すぎる ID)は、書いたままの文字にする
3. **指す先が無い参照は取り除く**(#287 で編集で開くときに取り除くのと同じ。消したページへのリンクが残っていたもの)。**下書きのカクテルを指す参照は、カクテルの名前だけの文字にする**(公開の詳細は 404 になるので、リンクにしない)
4. **改行は HTML にせず、文字の改行(`\n`・`\r\n`)のまま返す**。文字の区切りの中の HTML(`<b>` など)も、手を加えずに文字のまま返す。どう描くかは画面が決める(下の「画面での描き方」)
5. **隣り合う文字の区切りは 1 つにまとめ、空の文字の区切りは置かない**(3 で取り除いた・文字にした参照の前後もつなげる)
6. **説明文が null・空の文字なら null**(旧と同じ)。参照を取り除いて何も残らなければ、空の並び(`[]`)

## 画面での描き方(#301)

画面では `frontend/src/components/Description/` の `Description` が、この並びを描く(旧 `Detail/component/description.vue`)。

1. **リンクの区切りは、種類ごとに詳細へのリンクにする**: ノード → `/category/:id`、カクテル → `/detail/cocktail/:id`、銘柄 → `/detail/brand/:id`、用語 → `/dictionary/:id`。文字は指す先の名前
2. **`has_youtube` が true のリンクは、一覧の表の動画ありのリンクと同じ色(トークン `--color-has-movie`。`#c24e00`)にする**。指したときも色を変えない(旧と同じ)
3. **文字の区切りは HTML として描かない**。タグ(`<b>`・`<script>` など)や文字参照(`&amp;` など)は、書いたままの文字で出す。改行(`\r\n`・`\n\r`・`\r`・`\n`。旧の `nl2br` と同じく 1 つの改行として数える)だけを `<br>` にして改行として出す
4. **説明文が null・空の並びなら何も出さない**

## 旧との差分

テストの表では `差分あり(意図: docs/decisions/description-segments.md)` としてここを指す。旧での結果は、旧(本番の `laravel13`)の `Markup::generateDiscriptionArray` に、同じ説明文と、DB の代わりに置いた行を渡して出た結果。

- 区切りの形: 旧は `{txt}` と `{command: "C"|"P"|"M"|"B"|"D", id, txt, is_youtube}` → 新は `{type: "text", text}` と `{type, id, text, has_youtube}`。カテゴリ(`P`)とミドル(`M`)は、どちらもノード(`node`)になる(#285 で記法を `@n` にまとめた。#286 の「やること」1)
- 参照の前後の空の文字: 旧は説明文が参照で始まる・終わるとき、空の `{txt: ""}` を前後に置いていた(`@c1@` → `[{txt: ""}, {C}, {txt: ""}]`) → 新は置かない(決まったこと 5)
- 改行: 旧は `nl2br` で `<br />` を足していた(`"1行目<br />\n2行目"`) → 新は文字の改行のまま(#286 の受け入れ条件)
- 指す先の無い参照: 旧は型のエラーで API が 500 になり、ページごと出なかった → 新はその参照だけを取り除く(#286 の「やること」2・決まったこと 3)
- 下書きのカクテルを指す参照: 旧は下書きを見ずにリンクにしていた(開くと下書きの詳細が出た) → 新は名前だけの文字(#286 の「やること」2。下書きは公開の詳細で 404。`docs/decisions/cocktail-detail.md` の決まったこと 1)
- 用語の動画: 旧は用語のリンクに `is_youtube` を付けず、橙色にしなかった → 新は用語も `has_youtube` を返す(#286 の「やること」1。リンク先に動画があるか、を種類によらず返す)
- 記法の形でない `@`: 旧は `@` で切り分けたので、`@` が消えていた(`a@b.jp` → `"a"`・`"b.jp"` の 2 つの文字) → 新は書いたまま残す(決まったこと 2)
- 文字の区切りの中の HTML(画面。#301): 旧は `v-html` で HTML として描いていた(旧の `description.vue` を Vue 2 で描いた結果。`<b>太字</b>` は太字、`&amp;` は `&`、`<script>…</script>` は要素になり何も見えない) → 新は書いたままの文字で出す(#301 の「やること」3。改行だけを改行として出す)
- 動画ありのリンクの色(画面。#301): 旧は説明文のリンクも `#FF6600`(白地で 2.94:1) → 新は一覧の表と同じ `--color-has-movie`(`#c24e00`、4.79:1)。同じ意味の色を 2 か所で決めないため(#436 のオーナーの判断)
