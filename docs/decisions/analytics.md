# アクセス解析(GA4)とプライバシーポリシー

#59 で決めたこと。出どころは #59 の本文と、オーナーの決定のコメント(2026-10-25):

- GA4 を入れる。測定 ID は設定画面(#69)から入れる。未設定ならタグを出さない
- Cookie の同意バナーは出さない。代わりにプライバシーポリシーのページ(`/privacy`)を足し、GA4 を使っていることを書く。フッターからリンクする
- 新しいプロパティは作らず、旧サイトのプロパティを使い回す。測定 ID はコードに書かない。設定に入れるのは本番だけ(dev・stg のアクセスを旧サイトからの履歴に混ぜないため)

下の 3〜5 は、#59 の実装で決めた既定(問いにしなかったもの)。

## 決まったこと

1. **測定 ID は設定の `ga4.measurement_id`**(`App\Support\SettingDefinitions`。秘密にしない。`docs/decisions/settings.md`)。画面で保存していなければ `.env` の `GA4_MEASUREMENT_ID`。どちらにも無い・空なら、HTML にタグを入れない
2. **タグはサーバーが SPA の HTML(`backend/resources/views/spa.blade.php`)に入れる**(`App\Support\Ga4Tag`)。gtag.js を測定 ID 付きで読み込み、`gtag('config', <測定 ID>, { send_page_view: false })` を呼ぶ。測定 ID が未設定なら、gtag.js の読み込みも `gtag` の関数も HTML に無い
   - 測定 ID は HTML の属性と script の中に入るので、形(`G-` に英大文字と数字が続く、30 文字まで)の合うものだけを出す。管理画面での保存は同じ形で検査する(422)。`.env` の値は保存の検査を通らないので、形が違えばタグを入れずにログに残す
   - 設定を読めない(DB に繋がらない・表が無い)ときは、タグを入れずに HTML を返し、ログに残す。計測のためだけに、DB を引かない画面の HTML まで 500 にしないため
3. **page_view は SPA が送る**(`frontend/src/components/SiteLayout/usePageViewTracking.ts`)。公開ページの枠(`SiteLayout`)が、開いたとき・URL のパスかクエリが変わったときに `gtag('event', 'page_view', { page_location, page_title })` を呼ぶ。SPA は画面を移っても HTML を読み直さないので、タグの最初の page_view(`send_page_view`)は止めて、最初の 1 回もここで送る(二重にしない)
   - `page_location` は、開いている URL(オリジン + パス + クエリ)。同じ URL へのリンクを押しても送らない(スクロールの戻し方と同じく、旧の vue-router が同じ場所への移動を取りやめていたのに合わせる)
   - `page_title` は、移った画面がタイトルを書き換えた後の `document.title`。API の応答を待ってからタイトルを決める画面(カクテルの詳細など。タイトルはサイト名だけ)は、サイト名で送る。ページの区別は `page_location` でつける
4. **管理画面(`/admin` 以下)には、タグを入れず、page_view も送らない**。管理者の操作を、公開ページのアクセスの計測に混ぜないため
5. **プライバシーポリシー(`/privacy`)** には、GA4 を使っていること・Cookie で集める情報(個人を特定できる情報は入らないこと)・Google の案内へのリンク・情報を送らない方法(Cookie を無効にする、オプトアウトのアドオン)・内容を変えることがあることを書く。フッターの右に、同じタブで開くリンクを置く(旧の更新ボランティア募集のリンクがあった場所。#641 で消した)

## GA の管理画面で確かめること

- ウェブストリームの「拡張計測機能」の「ブラウザの履歴イベントに基づくページの変更」が有効だと、GA4 が画面の移動を自分でも page_view にして、上の 3 と二重に数える。無効にしておく(Google の SPA の計測の案内のとおり)。GA の管理画面の設定なので、コードでは確かめられない
- 測定 ID を本番の設定に入れたら、リアルタイムのレポートで、画面を移るたびに page_view が 1 件ずつ増えるかを見る(#59 の受け入れ条件)

## 旧との差分

旧の挙動は、旧の本番の版のソース(`laravel13/resources/views/welcome.blade.php`・`production-public/js/app.js`)を読んだもの。旧を動かして確かめてはいない(GA に送る通信を確かめるには、旧の測定 ID で旧のプロパティに送ることになるため)。

- タグの読み込み: 旧は UA の測定 ID を HTML に書き、どのページでもいつも gtag.js を読み込んでいた → 新は設定に GA4 の測定 ID があるときだけ、その ID で読み込む
- page_view の送り方: 旧は HTML を開いたときの `gtag('config', …)` が送る 1 回だけで、画面の移動では送るコードが無かった → 新は最初の 1 回の自動の送信を止め、公開ページを開いたとき・移ったときに SPA が送る
- 管理画面: 旧は管理画面も同じ HTML で、タグを読み込んでいた → 新は管理画面(`/admin` 以下)にタグを入れない
- プライバシーポリシー: 旧に無い(`/privacy` は旧では知らない URL で、トップを出していた) → 新はページを足し、フッターからリンクする
